# 시리즈로 묶기

시리즈는 **순서가 있는 글 묶음**이다. 카테고리·태그와 **독립적**이라, 서로 다른 카테고리의 글도 하나의 시리즈로 묶인다.

frontmatter 두 줄이면 된다. 중앙 설정 파일에 등록하는 절차는 없다.

```markdown
---
title: CDC 도입기 - 왜 필요했나
date: 2026-04-06
series: CDC 도입기
seriesOrder: 1
---
```

---

## 1. 규칙

| 필드 | 규칙 |
| :--- | :--- |
| `series` | 시리즈 이름. **같은 문자열**을 가진 글끼리 묶인다 |
| `seriesOrder` | 1부터 시작하는 순서. `series` 가 있으면 **필수** |

- **문자열이 정확히 같아야 한다.** 띄어쓰기 하나만 달라도 다른 시리즈가 된다
- `seriesOrder` 를 빠뜨리면 0이 되어 정렬이 무너진다
- 번호는 연속이 아니어도 되지만(1, 2, 5), 헷갈리니 연속을 권한다

---

## 2. 새 시리즈 시작하기

1. 시리즈 이름을 정한다 — 화면에 그대로 노출되므로 읽기 좋게
2. 첫 글에 `series` + `seriesOrder: 1` 을 넣는다
3. 끝. 시리즈 목록(`/series`)에 자동으로 나타난다

## 3. 기존 시리즈에 이어 붙이기

**마지막 순번을 먼저 확인**하고 다음 번호를 쓴다.

```bash
grep -rl "series: CDC 도입기" src/posts/ | xargs grep -h "seriesOrder"
```

시리즈 이름은 **복사해서 붙여넣는다.** 손으로 다시 타이핑하면 띄어쓰기가 어긋나 별개 시리즈로 갈라진다.

---

## 4. 무엇이 자동으로 생기나

시리즈에 속한 글에는 자동으로 붙는다.

- 글 상세 하단의 **이전 편 / 다음 편** 네비게이션
- 시리즈 전체 목차와 현재 위치 (`3 / 7`)
- `/series` 목록 페이지와 `/series/<이름>` 상세

따로 손댈 것이 없다. UI 구성은 [`engine/series.md`](../engine/series.md) 에 있다.

---

## 5. 언제 시리즈로 만드나

| 상황 | 판단 |
| :--- | :--- |
| 순서대로 읽어야 이해되는 연재 | 시리즈 |
| 같은 주제지만 순서는 무관 | 태그로 충분 |
| 한 편으로 너무 길어서 나눔 | 시리즈 |

순서가 의미 없다면 시리즈로 만들지 않는다 — 태그가 더 가볍다.
